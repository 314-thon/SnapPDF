# SnapPDF

[English](README.md) | [Español](README.es.md) | [Português](README.pt.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

---

ウェブページ全体や指定範囲を高品質なPDFおよびPNGとしてキャプチャし、**クリック可能なリンク**と**選択可能なテキスト**をそのまま保持できるChromium（Chrome, Edge, Brave, Opera）向けブラウザ拡張機能です。

外部サーバーとの通信、トラッキング、テレメトリは一切ありません。すべての処理はブラウザ内で完結します。

---

## 主な機能

- **リンクがそのまま機能するPDF:** 通常のツールのように単なる画像を貼り付けるのではなく、ページ内のすべての `<a>` タグを抽出し、正確な座標にPDFリンク注釈を埋め込みます。どのPDFリーダーでもリンクをクリックできます。
- **Ultra HD ミリ単位の精密レンダリング:** スクロール時の固定ヘッダーやナビゲーションバーの重複表示、不自然な分割線を完全に防止するスライシング合成エンジンを搭載。
- **テキスト検索・絵文字の選択に対応:** キャプチャ画像に合わせて不可視テキストレイヤー（UTF-16BE `/ActualText`）を配置。`Ctrl + F` でのページ内検索や、絵文字のコピー＆ペーストも文字化けせず行えます。
- **連続スクロールページまたはA4自動分割:** 1枚の縦長PDFとして書き出すことも、印刷に適した標準A4サイズへ自動分割して出力することも可能です。
- **クイックエクスポート & クリップボード対応:** PNG画像として保存できるほか、ワンクリックまたは `Ctrl + C` でクリップボードにコピーしてSlackやNotionにすぐ貼り付けられます。ページ内の全URLを一括テキストコピーすることも可能です。
- **プライバシー保護 & 完全ローカル実行:** クラウドへのデータ送信は一切行いません。画像や履歴が外部に流出する心配はありません。

## キーボードショートカット

| アクション | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **選択範囲をキャプチャ** | `Ctrl + Shift + S` | `Command + Shift + S` |
| **ページ全体をキャプチャ** | `Ctrl + Shift + E` | `Command + Shift + E` |
| **表示領域のみキャプチャ** | `Ctrl + Shift + X` | `Command + Shift + X` |

ショートカットの変更は `chrome://extensions/shortcuts` または `edge://extensions/shortcuts` からいつでも行えます。

## インストール手順（デベロッパーモード）

1. このリポジトリをクローンするか、ZIPファイルをダウンロードして解凍します。
2. Chromium系ブラウザを開き、拡張機能管理ページに移動します:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
3. 右上の **デベロッパーモード** を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**（Load unpacked）をクリックし、`SnapPDF` フォルダを選択します。
5. ツールバーにSnapPDFのアイコンが表示され、すぐに利用できます。
